1. Contexte et objectifs
NOVA est une marque fictive de mode urbaine. Le projet consiste à concevoir et développer un thème
Shopify Online Store 2.0 à partir de Shopify Skeleton. Le contenu marchand est administré dans Shopify
Admin ; les templates, sections, blocks et snippets assurent la présentation.
• Offrir une expérience cohérente sur ordinateur et mobile.
• Permettre au marchand de modifier les contenus dans Theme Editor sans changer le code.
• Rendre le parcours collection → produit → panier → checkout testable.
• Prouver des compétences transférables à des missions Shopify sur Upwork.

5. Règles métier et critères d’acceptation
• La collection affichée dépend de l’URL et de l’objet contextuel collection ; aucun handle produit ou
collection ne doit être codé en dur.
• Le composant product-card est réutilisé sur l’accueil et dans les collections.
• La sélection d’une variante doit utiliser son identifiant réel et actualiser prix, disponibilité et image si
nécessaire.
• Une variante indisponible ne peut pas être ajoutée au panier.
• Le panier reflète correctement les quantités et les montants après chaque modification.
• Le bouton de paiement redirige vers Shopify Checkout ; aucun système de paiement personnalisé n’est
développé.
• Les états vides (collection, recherche, panier) sont explicites et utilisables.
6. Architecture technique
Flux : Shopify Admin → objets Liquid / JSON templates → sections et blocks → snippets réutilisables →
HTML/CSS/JavaScript → storefront → Cart API → Shopify Checkout.
Conventions : architecture Online Store 2.0, paramètres dans schema, fichiers de traduction, styles
globaux cohérents, JavaScript progressif et dépendances minimales. Les noms de fichiers doivent suivre
la structure existante sans créer de composants en doublon.
Responsabilités : Shopify gère les données marchandes, les comptes et le checkout ; le thème gère
rendu, navigation et interactions côté navigateur.

9. Stratégie Git et assurance qualité
Développer par branches de sprint (feature/homepage, feature/catalog, feature/product-page,
feature/cart…), avec commits ciblés, revue et Pull Request vers main après validation. Vérifier les conflits
avant chaque fusion.
• Tests de parcours : collection → produit → variante → panier → checkout.
• Tests des tris et filtres, y compris avec zéro résultat.
• Tests mobile / desktop et navigation clavier.
• Vérification de la correspondance image–produit et du prix en USD.
• Contrôle du Theme Editor : modifier un paramètre doit mettre à jour le rendu.
• Exécuter Shopify Theme Check depuis la racine réelle du thème.
10. Livrables de fin de projet
• Thème Shopify fonctionnel dans un environnement de démonstration.
• Dépôt GitHub propre, README détaillé, instructions d’installation et de configuration.
