# Live demo recording plan

Record 60–120 seconds after connecting and verifying a development store. Do not substitute a mockup for a live storefront or show invented checkout success.

| Time | Shot | Narration focus |
| --- | --- | --- |
| 0–15s | Homepage, desktop then mobile | NOVA is a personal Shopify streetwear demo with merchant-editable content. |
| 15–30s | Collection filter and sort | Shopify catalogue data drives filters, prices and product cards. |
| 30–50s | Product variant and gallery | Real variant selection updates media, price and availability. |
| 50–70s | Add, change quantity, remove in drawer | Shopify responses determine cart totals; checkout remains native. |
| 70–90s | Search and product details | Predictive discovery and metafields enrich product content. |
| 90–110s | Theme Editor collection/image setting | Merchants change content without editing source. |
| 110–120s | Test checkout evidence or honest closing | Show a verified test order only after completing the acceptance matrix. |

Capture homepage at desktop/mobile, collection filters, product variant/media, cart drawer, search and Theme Editor settings. Use real demo product imagery with permission. Hide tokens, personal customer data and browser authentication screens. Save date, viewport, store/theme and test conditions with the evidence. Attach screenshots/video to the case study after verification; none were captured in this session.
