# Sprint 4: Contextual collection catalogue

Implemented contextual title/image/description, shared product grid, Shopify-provided sort options, configured boolean/list/price filters, active-filter removal, pagination and empty states. Numeric price inputs work without JavaScript; sliders enhance them. Filters use GET parameters and never hardcode catalogue handles. Collection default sorting is managed in Shopify Admin instead of an invalid theme sort schema. The native collapsible filter panel stays in document flow on mobile.

Validation: Theme Check, 51 files, zero offenses. Live filter configuration and responsive checks require the development store.
